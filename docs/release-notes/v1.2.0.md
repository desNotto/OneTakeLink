## Скачать / Download

- **`OneTakeLink-1.2.0-setup-windows-x64.exe`** — установщик / installer (рекомендуется / recommended)
- `OneTakeLink-1.2.0-windows-x64.zip` — портативная версия без установки / portable, no installation

Windows 10/11 x64. Файлы не подписаны цифровой подписью: при предупреждении SmartScreen — «Подробнее» → «Выполнить в любом случае».
The files are not code-signed: on a SmartScreen warning — "More info" → "Run anyway".

### Русский

- Звук со звуковой карты компьютера. Галочка «Записывать звук» перенесена в панель «Источник»; когда она включена, выбирается источник звука:
  - «С камеры (микрофон телефона)» — как в 1.1.0;
  - вход звуковой карты — каналы «Стерео (1+2)», «Канал 1» или «Канал 2» (моно на обе стороны), индикатор уровня, «Сдвиг звука» ±1000 мс.
  - Синхронизация: iPhone — по часам LensLink автоматически; Android — по моменту прихода кадров, задержку при необходимости подбирать сдвигом.
- Панель справа: «Источник», «Запись», «Камера», «Фактический поток». «Камера iPhone» переименована в «Камера». «Фактический поток» свёрнут по умолчанию (в заголовке — разрешение и FPS), раскрывается щелчком.
- Выбор языка — флажки России и США на верхней панели.
- `otl-cli audio-inputs` — список входов звука; `otl-cli record ... --audio-input=N` — запись со звуком со входа N.

### English

- Audio from the computer's sound card. The "Record audio" checkbox moved to the Source panel; when it is on, the audio source is selected:
  - "From the camera (phone microphone)" — as in 1.1.0;
  - a sound-card input — "Stereo (1+2)", "Channel 1" or "Channel 2" (mono on both sides), level meter, "Audio offset" ±1000 ms.
  - Sync: iPhone — automatically from the LensLink clock; Android — from frame arrival times, tune the delay with the offset if needed.
- Right panel: Source, Recording, Camera, Actual stream. "iPhone camera" renamed to "Camera". Actual stream is collapsed by default (resolution and FPS in its header) and expands on click.
- Language selection — Russian and US flags in the top bar.
- `otl-cli audio-inputs` lists audio inputs; `otl-cli record ... --audio-input=N` records with audio from input N.
