### Русский

Первая версия OneTakeLink — записи видео с камеры телефона на Windows.

- **iPhone** через приложение LensLink Camera (App Store): USB или Wi-Fi, запрос режима 1080p 60 fps, управление камерой (режим, объектив, зум, экспокоррекция, фиксация фокуса/экспозиции/баланса белого).
- **Android 12+** по USB: через adb и сервер scrcpy из комплекта, без установки приложений на телефон; выбор камеры, режима (720p–4K, 30/60 fps), битрейта, H.264/H.265.
- **Запись в MP4 без перекодирования** (поток телефона как есть, без звука); восстановление дубля после сбоя или отключения питания; сохранение записанного фрагмента при обрыве связи; контроль места на диске; папки проектов и сессий; таймер старта.
- **Монитор**: фактические разрешение, FPS, битрейт, пропуски кадров, задержка; рамка формата 16:9 / 9:16 / 4:5 / 1:1; безопасные зоны Instagram Reels и YouTube Shorts; сетка третей; поворот кадра на 90° (записывается в файл без перекодирования); полноэкранный режим.
- **Медиатека**: миниатюры или таблица, поиск, фильтры по проекту и избранному, сортировка, встроенный плеер с покадровым шагом, переименование, удаление в Корзину.
- Интерфейс на одном экране, русский и английский языки.
- Установщик: установка для всех пользователей или только для себя, правило брандмауэра для Wi-Fi-подключения iPhone; при удалении стираются программа, настройки, кэш и журналы — записи остаются.

### English

First release of OneTakeLink — recording video from a phone camera on Windows.

- **iPhone** via the LensLink Camera app (App Store): USB or Wi-Fi, requests 1080p 60 fps, camera control (mode, lens, zoom, exposure compensation, focus/exposure/white-balance lock).
- **Android 12+** over USB: via the bundled adb and scrcpy server, nothing installed on the phone; camera, mode (720p–4K, 30/60 fps), bitrate, H.264/H.265.
- **MP4 recording without re-encoding** (the phone's stream as is, no audio); take recovery after a crash or power loss; the recorded part is kept on connection loss; disk-space checks; project and session folders; start countdown.
- **Monitor**: actual resolution, FPS, bitrate, dropped frames, latency; 16:9 / 9:16 / 4:5 / 1:1 format frame; Instagram Reels and YouTube Shorts safe zones; rule of thirds; 90° frame rotation (stored in the file without re-encoding); full screen.
- **Media library**: thumbnails or table, search, project and favourites filters, sorting, built-in player with frame stepping, rename, delete to Recycle Bin.
- Single-screen interface in Russian and English.
- Installer: per-machine or per-user install, firewall rule for iPhone Wi-Fi connection; uninstall removes the program, settings, cache and logs — recordings stay.
