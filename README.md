# OneTakeLink

Бесплатная программа для Windows 10/11, чтобы снимать дубли игры на гитаре
на камеру iPhone: подключить телефон → проверить кадр → записать несколько
дублей → выбрать удачный → кадрировать и экспортировать (например, в Instagram).

Без рекламы, подписок, водяных знаков и регистрации. Работает без интернета,
все записи и настройки хранятся только на вашем компьютере.

Видео с iPhone принимается через официальное приложение
**[LensLink Camera](https://apps.apple.com/app/lenslink-camera/id6790673163)**
(App Store). Модуль подключения в OneTakeLink — это переработанная без OBS
Windows-часть открытого проекта [LensLink](https://github.com/MyNamesEMurray/LensLink).

> Статус: **версия 0.1 — рабочий прототип** (этапы 1–2 ТЗ и основа этапа 3).
> Полное техническое задание: [`docs/spec/Technical_Specification_OneTakeLink_v1.0.txt`](docs/spec/Technical_Specification_OneTakeLink_v1.0.txt).

## Что уже умеет

- Подключение к iPhone **по USB** (через службу Apple Mobile Device Service)
  и **по Wi-Fi** (поиск в сети через Bonjour или ввод IP вручную).
- Автоматическое переподключение при обрыве связи, понятные подсказки, что проверить.
- Автозапуск камеры на iPhone и запрос режима **1080p 60 fps** при подключении.
- Мониторинг с минимальной задержкой (аппаратное декодирование D3D11VA/DXVA2).
- **Фактические** параметры потока: разрешение, FPS, битрейт, пропуски кадров,
  задержка, тип декодера.
- Управление камерой iPhone: режим (разрешение/FPS), объектив, зум,
  экспокоррекция, фиксация фокуса, экспозиции и баланса белого (только то,
  что реально поддерживает телефон).
- Направляющие: сетка третей, центр, безопасная зона, рамка кадрирования
  16:9 / 9:16 / 4:5 / 1:1 с затемнением. В запись не попадают.
- **Запись в MP4 без перекодирования** (H.264 с телефона, без звука) — без потери
  качества и почти без нагрузки на ПК.
- Защита записи: дубль пишется так, что при сбое программы или отключении
  питания он восстанавливается при следующем запуске; при потере связи
  сохраняется уже записанный фрагмент; контроль свободного места.
- Папки проектов и сессий: `Проект/Session_ГГГГ-ММ-ДД/ГГГГ-ММ-ДД_Проект_Take_001.mp4`.
- Таймер перед записью (3/5/10 с), горячие клавиши, полноэкранный режим.
- Библиотека: список дублей с длительностью, разрешением, FPS, кодеком;
  избранное, переименование, удаление в Корзину, открытие во внешнем
  проигрывателе и в Проводнике.

## Как пользоваться

1. Установите на iPhone **LensLink Camera** из App Store.
2. Для USB: установите на ПК **iTunes** или **Apple Devices** (Microsoft Store),
   подключите iPhone кабелем, разблокируйте и нажмите «Доверять этому компьютеру».
   Для Wi-Fi: телефон и ПК в одной сети; при первом запуске разрешите
   OneTakeLink в брандмауэре Windows.
3. Откройте LensLink Camera на iPhone.
4. В OneTakeLink выберите устройство (по умолчанию — первый iPhone по USB)
   и нажмите **Подключить**.
5. Проверьте кадр, нажмите **REC** (или Space). Остановка — ещё раз Space.
6. Дубль сразу появляется во вкладке **Библиотека**.

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Space | REC / STOP |
| F11, двойной клик по видео | Полноэкранный режим |
| Esc | Выход из полноэкранного режима |
| Delete | Удалить выбранные дубли (в Корзину, с подтверждением) |
| F2 | Переименовать дубль |
| F | Избранное |
| F5 | Обновить библиотеку |

### Почему дубль начинается чуть раньше нажатия REC

Видео с iPhone сжато, и файл может начинаться только с ключевого кадра (раз в
2–4 секунды). Поэтому OneTakeLink начинает дубль с последнего ключевого кадра
**до** нажатия REC: начало игры никогда не обрезается. Лишние секунды
можно будет отрезать при экспорте (этап 4).

## Диагностика: `otl-cli`

Рядом с программой лежит консольная утилита для проверки связи (этап 1 ТЗ):

```bat
otl-cli devices
otl-cli monitor usb 600
otl-cli record usb test.mp4 60
otl-cli recover "C:\Users\Вы\Videos\OneTakeLink"
```

`monitor` раз в секунду печатает фактическое разрешение, FPS, пропуски кадров,
битрейт и задержку — так проверяется длительная стабильность 1080p60 на
конкретном iPhone, кабеле и ПК. Журнал программы:
`%LOCALAPPDATA%\OneTakeLink\logs\onetakelink.log` (никуда не отправляется).

## Сборка из исходников

Нужны CMake ≥ 3.21, Qt ≥ 6.4 (Widgets, OpenGLWidgets), FFmpeg (avcodec,
avformat, avutil, swscale). На Windows (Visual Studio 2022):

```bat
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release ^
      -DCMAKE_PREFIX_PATH=C:\Qt\6.8.3\msvc2022_64 ^
      -DFFMPEG_ROOT=C:\ffmpeg-7.1.1-full_build-shared
cmake --build build
```

Без iPhone можно проверить всю цепочку эмулятором телефона:
`python tools/fake_phone.py`, затем в программе подключиться к
`Wi-Fi — ввести IP вручную…` → `127.0.0.1` (или `OneTakeLink --connect=wifi:127.0.0.1`).
